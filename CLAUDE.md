# Proofpress governed context

When this project connects to Proofpress through MCP:

- Before relying on durable agent-produced knowledge, retrieve only eligible, in-scope governed context and preserve its scope and limits.
- For a durable decision, evidence-backed conclusion, reproducible experiment result, integration contract, or incident learning, submit a bounded proposal with the minimum supporting evidence. Never send secrets, credentials, or raw private traces.
- Agents may inspect, propose, evaluate, and retrieve eligible context, but may not approve a proposal, use owner or recovery credentials, change policy, or administer credentials.
- If MCP is unavailable, governed reuse is blocked. Do not substitute local memory or an unreviewed conclusion and describe it as approved context.
