# Proofpress landing page

The public, hero-first landing page for Proofpress.

```bash
npm install
npm run dev
npm test
npm run build
```

For Vercel, set the project root directory to `web/landing`. The included
`vercel.json` publishes Vite's `dist` output and provides the SPA fallback.

The primary call to action opens the repository's design-partner issue form.
Public copy must remain within the current product boundary documented in
`../../docs/DESIGN.md` and the product documentation; do not add outcome,
multi-owner, or multi-tenant claims without validation.
