# Receiver-model configuration

[//]: # (ob:0477a0a4)
This is an evaluation configuration, not a trained model specification. Exact requested and resolved model/provider pairs, fallback state, token usage, latency, and provider-reported cost are retained in the machine-readable evidence summaries. Formal comparisons prohibit provider fallback and cross-router retry.

[//]: # (ob:ecb75eaf)
The main controlled follow-up uses the frozen receiver task with GLM 5.2, Kimi K3, and Qwen 3.8 Max in separately reported model slices. The preregistered comparison uses Luna. These names describe evaluation endpoints rather than model endorsements; Proofpress itself makes no model call.
