# Environment

[//]: # (ob:a84a1149)
- **Experiment repository**: repository-relative root `experiments/provenance_handoff/`.
- **Experiment runtime**: Python project managed with `uv`; individual runners record their own dependencies and resolved model routes.
- **Study status**: the local experiment program summarized by this ARA is complete. STALE/CUPMem and Harvey LAB runs are historical branches and are not the primary admission evidence.
- **ARA upstream**: `https://github.com/ARA-Labs/Agent-Native-Research-Artifact`, local source commit `35981edc35c51413d291ab8e504ea7c907fd67e7`.
- **External data home**: `PROOFPRESS_EVAL_HOME`; raw data/traces/results stay there.
- **Model transport**: formal comparisons lock requested/resolved model, provider, retries, and fallback state. Cross-router retries and provider fallback are excluded from formal cells. Credentials remain outside Git.
- **Model policy**: the completed studies use the frozen model routes documented per experiment; Proofpress itself never makes a model call.
- **Telemetry rule**: qualified model calls record requested/resolved model, actual provider, fallback metadata, token values, latency, and cost when the transport exposes it. A missing required field remains audit-visible but is not silently treated as zero.
- **Reproduction boundary**: aggregate evidence is included here, while some raw traces and immutable reports remain in `PROOFPRESS_EVAL_HOME`. A public reproduction archive must vendor or archive the permitted subset and replace local-only pointers with stable URLs and checksums.
