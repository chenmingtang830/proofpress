## Release evidence map

[//]: # (ob:687aeafa)
The principal reader-facing synthesis is [derived_main_results.md](tables/derived_main_results.md), with a rendered companion at [derived_main_results.png](tables/derived_main_results.png). It reports the clean-versus-outdated admission comparisons, receiver-model robustness, visible-contradiction boundary, selective revalidation, continuity result, and measured token, latency, and cost overhead. Values are derived from the machine-readable summaries and canonical reports listed below; the table is not a new experiment.

[//]: # (ob:563cb8db)
The primary machine summaries in this ARA are `cross-model-formal-summary-20260812.json`, `cross-model-kimi-summary-20260812.json`, `cross-model-qwen-summary-20260812.json`, `knowledge-handoff-early-results-20260812.json`, `results-matrix-cross-model-formal-20260812.json`, and `deepseek-track2-gateway-overhead-20260813.json`. The experiment registry in [`../logic/experiments.md`](../logic/experiments.md), the paper appendices, and the qualification notes in this index distinguish valid treatment evidence from diagnostics, compatibility checks, and transport failures. Invalid and superseded local execution records are intentionally not redistributed.

[//]: # (ob:4a2a703a)
The current ARA contains aggregate metrics, selected machine summaries, hashes, and evidence pointers. Raw prompts, full traces, credentials, original third-party benchmark tasks, and some immutable run reports remain outside Git in `PROOFPRESS_EVAL_HOME`. Therefore this directory supports review of the reported claims but is not a self-contained archive for rerunning every model call.
