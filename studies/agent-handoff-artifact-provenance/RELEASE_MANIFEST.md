# Release manifest — candidate `rc1`

[//]: # (ob:b4ea023e)
## Included

[//]: # (ob:02e04a0e)
- The complete ARA source package under `ara/`.
- A reader-facing technical report and main-result table.
- Aggregate and selected machine-readable result summaries already committed to the ARA evidence layer.
- Protocol descriptions and repository-relative implementation pointers.
- Proofpress revision capsules embedded in accepted Markdown artifacts where applicable.

[//]: # (ob:72cbdec6)
## Excluded

[//]: # (ob:253f71e3)
- API credentials and provider account data.
- Raw prompts, private traces, and full model outputs stored outside Git.
- Local cache directories and machine-specific immutable run roots.
- Original third-party benchmark tasks, source documents, prompts, and answer keys. The package contains only study-authored descriptions, aggregate results, and selected machine summaries needed to audit the reported claims.
- Failed-run detail from the main narrative; diagnostic and superseded paths remain indexed in the ARA appendices where redistributable.

[//]: # (ob:6c46a2e5)
## Release readiness checks

[//]: # (ob:4d17e537)
- Machine-local roots in released summaries are normalized to non-resolving `local-run://` identifiers.
- No original third-party benchmark task material is redistributed in this package.
- `SHA256SUMS` covers every released file except the checksum manifest itself.
- ARA Seal Level 1, JSON/YAML parsing, public Markdown links, secret scanning, Python compilation, and Git whitespace checks pass on the frozen candidate.
- A fixed Git commit and tag must be created at publication time and used in social posts and citations.
