# APEX Agent Evaluation

[//]: # (ob:2dfe709c)
This independent pilot evaluates a Proofpress governed working-set treatment on two legal tasks from one public APEX world.

[//]: # (ob:e552dfdb)
Start with [the ARA paper](ara/PAPER.md). Exact frozen study inputs are retained as audited manifests under [`ara/evidence/raw/`](ara/evidence/raw/); corpus files, generated DOCX files, credentials, runtime state, and raw model outputs are intentionally excluded.

[//]: # (ob:a242760f)
The runnable Athena-shaped proof of concept is retained as a separate private [reference implementation](REFERENCE_IMPLEMENTATION.md), pinned to an immutable commit. [`ARTIFACT_INDEX.json`](ARTIFACT_INDEX.json) records the canonical study evidence, companion documentation, and deliberate exclusions without copying the application or restricted data room into this repository.

[//]: # (ob:e2a35669)
The reported quality summaries are co-primary descriptive views: majority passed rubric cells and mean passed rubric cells across repeated grader judgments of each single generated artifact. The study used staged candidate claims, not lawyer-admitted knowledge, and native Archipelago output grading over locally generated artifacts, not official APEX Pass@1.

[//]: # (ob:020bad83)
The companion application is a runnable reference implementation, not the Proofpress product source. Reusable mechanisms resolve to the claim-centric CLI, retrieval-receipt, adapter, and test implementations maintained in this repository.
