# Superseded Harvey LAB contract-negotiation planning record

[//]: # (ob:0da70121)
This directory preserves the planning lineage for a proposed multi-stage contract-negotiation evaluation. It is not an active benchmark and must not be used to justify a new evaluation run: the completed, frozen successor is the [Harvey LAB-derived governed long-horizon study](../long-horizon-eval/relaybench/README.md).

[//]: # (ob:0da70122)
## What this folder is for

[//]: # (ob:0da70123)
Read the [original research plan](RESEARCH_PLAN.md) only to understand the pre-study hypothesis, intended intervention, and exclusions. It reports no independent results and must not be treated as evidence separate from the completed successor.

[//]: # (ob:0da70124)
## Retained planning sources

[//]: # (ob:0da70125)
The related planning records are retained at their existing `studies/` paths because frozen RelayBench manifests and alignment records bind those paths and digests. [ARCHIVE_MAP.md](ARCHIVE_MAP.md) places them in this historical folder conceptually without duplicating or mutating receipt-bound inputs.
