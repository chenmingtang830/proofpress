# Long Horizon Eval ARA

[//]: # (ob:a71389fb)
## Role

[//]: # (ob:71ee4330)
This Agent Research Artifact (ARA) is the canonical lifecycle record for the completed Proofpress long-horizon contract-negotiation evaluation. It organizes research semantics, protocol choices, admitted evidence, receipts, and claim boundaries; it is not itself a substitute for the underlying run records or Proofpress verification.

[//]: # (ob:21168fbc)
## Current state

[//]: # (ob:4c8f145b)
The study is frozen complete. Seven model panels contribute 126 valid paired runs across Credit, MSA, and License task families. Historical Phase Zero fixtures remain retained as mechanics evidence but are excluded from every reported result.

[//]: # (ob:a35a7d6e)
## Lifecycle

[//]: # (ob:7130299a)
1. **Design** — define the claim boundary, H4 episode, C1/C2 conditions, and measurement families.
2. **Freeze** — approve source revisions, candidate matter, stage composition, rubrics, semantic parity, and execution settings before a real call.
3. **Execute** — retain complete run records, invalid/partial attempts, and environment/provider telemetry.
4. **Admit** — check that each result is bound to the frozen protocol, approved sources, and recorded execution evidence before it contributes to a claim.
5. **Synthesize** — derive only the claims supported by admitted records, keeping mechanism, effectiveness, integrity, and legal-quality claims distinct.
