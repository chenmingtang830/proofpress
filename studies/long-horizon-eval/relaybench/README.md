# RelayBench — frozen long-horizon handoff study

[//]: # (ob:f912c31c)
RelayBench is the execution, cold-boundary, governance, aggregation, and reporting layer for the Proofpress long-horizon handoff study.

[//]: # (ob:ff436f24)
The final frozen panel contains seven models, three legal task families, and 126 valid paired runs. Across this bounded panel, ordinary handoff scored 10,654/11,928 rubric criteria (89.3%) and Proofpress scored 11,141/11,928 (93.4%), a descriptive difference of +4.1 percentage points. In 63 controlled stress pairs, observed unsafe propagation fell from 8 events to 0.

[//]: # (ob:979c2fd0)
These are Proofpress-composed, Harvey LAB-derived handoff tasks built from version-pinned public materials. They are not official Harvey leaderboard results or a population-level causal estimate. Start with [`PUBLIC_RESULTS.md`](PUBLIC_RESULTS.md), then inspect [`CLAIM_BOUNDARIES.md`](CLAIM_BOUNDARIES.md), the [ARA evidence index](../ara/evidence/README.md), and the immutable files under [`results/`](results/).

## Review and validation

[//]: # (ob:3c4f2a78)
Requires Node.js 22 or newer. The project has no runtime package dependency.

[//]: # (ob:f79e70a9)
```sh
npm install
npm run check
```

[//]: # (ob:bf8dbb39)
Run the synthetic mechanics calibration in a disposable output directory:

[//]: # (ob:bbd0a989)
```sh
node scripts/bench-run.mjs --adapter deterministic-test --test-only --paired-replicates 1 --output /tmp/relaybench-h4/test-only
node scripts/bench-score.mjs --input /tmp/relaybench-h4/test-only --output /tmp/relaybench-h4/test-only/score.json
node scripts/bench-report.mjs --input /tmp/relaybench-h4/test-only --output /tmp/relaybench-h4/test-only/report.md
```

[//]: # (ob:4cb1cca8)
The scorer and reporter exclude TEST-ONLY episodes. Historical Phase Zero documents remain in this directory as calibration records; they do not describe the final study state and never enter result denominators.

[//]: # (ob:80648521)
The study is frozen. Additional models or scenarios require a new preregistered study rather than extending this result after outcomes are known.
