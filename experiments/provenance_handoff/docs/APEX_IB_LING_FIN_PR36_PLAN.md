# Ling Fin APEX Investment Banking PR36-Style Experiment Plan

[//]: # (ob:c6ee48d6)
## Status and authorization boundary

[//]: # (ob:e16da70c)
This is the active implementation and execution plan for the local Ling Fin APEX Investment Banking study in the production `chenmingtang830/proofpress` repository. It has its own `codex/finance-layered-ling` branch and pull request and is independent of Legal PR #53. It supersedes the post-hoc receiver comparison as the basis for any treatment-effect analysis. The existing completed `task_9ba58a6197114140877a1df1754d2993` run is qualification evidence only and is excluded from the formal denominator.

[//]: # (ob:378d35e0)
The closed proofpress-dev PR #17 and every run launched from that checkout are wrong-repository diagnostics only. The interrupted layered calibration built one candidate treatment but completed no executor artifact and no grader repetition; it contributes 0 to every formal denominator. Only runs launched by the production-repository entrypoint `experiments/provenance_handoff/run_finance_layered.py` may enter this study.

[//]: # (ob:25055dc8)
The study is a local, descriptive pilot. It does not establish official APEX Pass@1, investment correctness, production admission, or human authorization of agent-proposed claims. Candidate claims are staged research context unless an authorized human separately admits them.

[//]: # (ob:99151f17)
## Research question

[//]: # (ob:7e5688bf)
For a fresh `inclusionai/ling-3.0-flash-fin` executor completing the same APEX Investment Banking task from the same frozen world, does replacing full-data-room access with a Proofpress governed working set preserve native task quality, change executor effort, and prevent execution when a material source-state conflict is detected? Ling is the fixed downstream executor in both arms; it is not presumed to be the best model for every upstream extraction, proposal, or criticism stage.

[//]: # (ob:b99b0eb0)
The primary contrast is systems-level and intentionally matches the PR36 APEX design:

[//]: # (ob:fd8cb847)
- **Normal**: task instructions, pristine workbook, and the full frozen data room.
- **Proofpress**: the same task instructions and byte-identical pristine workbook, plus a bounded governed working set produced before executor invocation; the executor cannot access the full data room.

[//]: # (ob:6ebe8fe3)
No ordinary bounded-context ablation is part of this study. Such an ablation may be designed later and must not be pooled with this matrix.

## Finance routing qualification before treatment construction

[//]: # (ob:6dc1e0d5)
The Finance study has two stages that must not be pooled. First, a development-only routing qualification tests upstream components on the same frozen data room without invoking the formal executor or native grader. Deterministic code owns file inventory, digests, workbook extraction, locators, receipts, observed-fact construction where possible, graph validation, claimability, and the execution gate. Candidate models may perform task decomposition, evidence-atom extraction, risk or interpretive proposal, and independent criticism. The exact slug, provider, reasoning level, prompt/config digest, fallback policy, latency, token usage, and cost are frozen for every call.

[//]: # (ob:386b0e6b)
The qualification reports exact requirement coverage, explicit-atom validity, qualification retention, unsupported or over-broad claim rate, conflict detection, schema completion, and escalation rate. A premium model verdict is a diagnostic reference, not gold and not admission. Ling may be included as a sensitivity candidate, but free price does not promote it into a trust-critical role. The first implementation freezes `deepseek/deepseek-v4-flash` as the treatment proposer because it separates treatment construction from the Ling executor; any critic or premium escalation must be independently recorded before it can affect a formal working set.

[//]: # (ob:1588411a)
Only a routing configuration that completes all frozen development tasks, preserves 100% source/locator/digest binding, has complete terminal telemetry, contains no requested final-output leakage, and passes the deterministic execution gate may build a calibration treatment. Failure stops the formal matrix and remains a qualification result with zero formal executor denominator.

[//]: # (ob:62127e36)
## Treatment construction

[//]: # (ob:962964ee)
The Proofpress arm is constructed before the executor starts:

[//]: # (ob:a061dd8b)
1. Inventory the frozen world and bind each file to a digest.
2. Decompose the public task prompt into explicit requirements without reading rubrics or gold data.
3. Perform deterministic workbook and document extraction with sheet, cell, range, page, section, and source-digest locators.
4. Use the frozen qualified proposer route, initially a fresh `deepseek/deepseek-v4-flash` session, to propose atomic candidate claims from the bounded evidence.
5. Run any qualified critic or premium escalation as a separate model session and retain its verdicts; it may reject or narrow proposed claims but cannot admit them. Until that independent stage is qualified, the deterministic gate remains the only promotion authority and the limitation is explicit.
6. Deterministically verify source identity, locator validity, quote/value binding, units, dates, and graph references.
7. Obtain a non-authoritative Ling Fin policy recommendation; it cannot admit claims.
8. Stage eligible claims as research-only context and record residual gaps.
9. Select the task-scoped graph using deterministic traversal over typed relations such as `derived_from`, `depends_on`, `qualifies`, `supersedes`, and `conflicts_with`.
10. Evaluate the pre-execution integrity and reliance gate. Invoke the executor only on `allow`.

[//]: # (ob:6ff19889)
The working set may include source-bound financial inputs, definitions, assumptions, formulas, dependencies, units, dates, and caveats. It must not include the requested final output values or any hidden benchmark criterion. A post-freeze leakage audit may invalidate a package but may not be used to iteratively optimize a formal package against hidden answers.

[//]: # (ob:63ffa436)
## Executor contract

[//]: # (ob:402a2f21)
Every executor cell uses a fresh writable workspace and an immutable pristine base. The exact executor model is `inclusionai/ling-3.0-flash-fin`; provider route, adapter revision, model parameters, tool policy, maximum 60 agent steps, and 2,400-second wall-clock limit are frozen in the run manifest.

[//]: # (ob:8a89eb62)
Normal and Proofpress cells receive identical public task instructions and pristine workbook bytes. Normal receives the full world. Proofpress receives only its task-scoped evidence bundle and governed working set. The final executor is a fresh Ling session in both arms; upstream treatment models never continue into execution. Neutral workspace names must not expose arm labels. No cell may reuse another cell's modified workbook, agent session, or runtime state.

[//]: # (ob:86542386)
Executor cells run serially. Within each paired block, arm order is assigned from a recorded deterministic randomization seed. A valid model timeout is retained as an outcome and is never selectively rerun. An infrastructure abort invalidates the entire pair; both arms rerun under a new pair identifier while the invalid record remains immutable.

[//]: # (ob:c1f63456)
## Arm-neutral native grading

[//]: # (ob:b876de93)
The fixed native Output LLM verifier is `google/gemini-3.1-pro-preview` through the recorded Vercel AI Gateway route. The grader receives only the public task, the identical initial artifact package, the arm-neutral final response, and the expected final workbook/diff package.

[//]: # (ob:35ee45ff)
Proofpress claims, graph files, receipts, capsules, trajectories, treatment labels, and treatment-specific filenames are excluded from the native grading package. Both arms expose identical package structure. Each formal artifact is graded three times independently; the majority judgment for each native criterion determines the artifact-level criterion result. Grader repetitions are not executor repetitions.

[//]: # (ob:5f169260)
The primary quality endpoint is the majority native rubric fraction per executor artifact. Secondary endpoints are exact all-criteria success and criterion-level paired gain/tie/loss. Results must distinguish local native grading from official APEX Pass@1.

[//]: # (ob:625a5d7b)
## Formal matrix and metrics

[//]: # (ob:d23f9f25)
The formal matrix contains two tasks, two arms, and three independent executor attempts per arm: 12 executor artifacts. The calibration pair adds two non-formal artifacts. Stress cells are separate safety tests and should invoke no executor when the gate works.

[//]: # (ob:b9a8da55)
For each artifact record native rubric outcomes, exact success, workbook validity, wall-clock time, model tokens, agent steps, tool calls, file/search activity, timeout state, provider telemetry, and artifact digests. Separately record treatment preparation time and tokens, extraction counts, proposed and staged claim counts, coverage gaps, new versus reused claims, working-set size, and gate decision.

[//]: # (ob:441c90c3)
Executor-only efficiency and cold-start end-to-end cost are reported separately. Task 2 claim reuse may support an amortized descriptive view, but missing preparation telemetry must not be imputed. The study is too small for a generalized statistical claim; publish exact denominators, paired deltas, exclusions, and invalid cells.

[//]: # (ob:26c3d4d1)
## Safety stress tests

[//]: # (ob:342726ae)
Freeze one material corruption for each formal task before stress execution. At least one stress case must change a material source or workbook digest after working-set construction; the other must introduce a same-scope, same-effective-date claim conflict that would change the permitted calculation basis.

[//]: # (ob:c6a5323a)
A stress cell passes only when the gate records the conflicting state, identifies the affected requirement, blocks before executor invocation, and produces no client workbook. Blocked cells receive no quality score and are not treated as zero-quality artifacts.

[//]: # (ob:6fdad12a)
## Contract and preflight gates

[//]: # (ob:30620cd8)
Before calibration, automated checks must prove that task/world identities and pristine digests are frozen; builder inputs exclude rubrics, gold data, and prior answers; Normal has full-room access; Proofpress lacks full-room access; both arms start from identical workbook bytes; prompts and neutral paths do not leak treatment; grading packages are arm-neutral; treatment sidecars cannot reach the native grader; runtime/model limits match; resume never overwrites a prior record; and tampering fails closed.

[//]: # (ob:ad4b8dee)
Host preflight requires a healthy Docker runtime, the retained cached environment image, a successful Ling Fin canary, a successful Gemini grader canary, and at least 20 GiB free before the compacted calibration pair and 25 GiB before the formal matrix. These are executable host gates, not a recommendation that macOS normally run this close to capacity. Docker storage is not migrated. A single pristine world archive is retained; each cell stores changed artifacts, final response, trajectory, grades, manifests, and reconstruction digests rather than duplicating the full world.

[//]: # (ob:0a98cde3)
Calibration may authorize formal execution only when protocol mechanics and telemetry are valid. Calibration score direction cannot be used to tune the treatment. A leakage, access-parity, model-drift, grader-blinding, digest, storage, or incomplete-artifact failure stops the affected pair and preserves it as invalid evidence.

## Production execution status — 2026-08-28

[//]: # (ob:df9c7547)
Production calibration completed one non-formal pair. The DeepSeek treatment builder produced 90 proposed claims and 119 relations across seven requirements with six residual gaps; the deterministic gate allowed execution. Normal Ling scored 1.0 in 775.026 seconds and Proofpress Ling scored 1.0 in 532.712 seconds. This pair is calibration only, so the formal denominator remains 0/12 and the observed latency difference is not a treatment-effect estimate.

[//]: # (ob:92d887a6)

The stopped launch contributes 0 executor artifacts and 0 grader repetitions. Formal execution may resume only after executor, proposer, and grader telemetry is persisted and the no-fallback/cost-completeness gate passes.

[//]: # (ob:b51ba0f2)

All 8/8 Gemini calls recorded the frozen model, Vertex provider, one model attempt, token usage, and terminal Gateway cost: 437,908 prompt tokens, 4,274 completion tokens, 442,182 total tokens, and $0.927104. This was a telemetry canary only and contributes zero artifacts or repetitions to the formal denominators. The next admissible step is a fresh full calibration pair with three independently persisted native grading repetitions per artifact; only that end-to-end receipt chain may release a new formal run directory.

## Evidence and completion criteria

[//]: # (ob:9d8345fc)
Frozen configuration lives under `configs/frozen/apex-ib-ling-fin-pr36-v1/`. Auditable study evidence lives under `evidence/apex-ib-ling-fin-pr36-v1/` and includes source and model manifests, working-set digests, cell receipts, invalid-run records, grading receipts, stress receipts, artifact digests, a reconstruction index, and the final paired results matrix. Raw credentials, licensed/restricted data-room bytes, raw prompts, and private reasoning are excluded from Git and from the Proofpress ledger.

[//]: # (ob:3d582283)
The study is complete only when the upstream Finance routing qualification passes its frozen gates; the fresh calibration pair passes all protocol gates; all 12 formal executor cells have valid immutable outcomes or explicitly preserved valid timeouts; every formal artifact has three completed native grading repetitions; both stress cells have receipts; every reported denominator reconciles to the run index; retained artifacts reconstruct and verify; and the final report states quality, efficiency, preparation-cost, safety, authority, and official-score boundaries without inflating the evidence. The paused 2026-08-28 attempt remains a diagnostic interruption with zero formal executor and grader denominator and is never combined with the restarted study.
