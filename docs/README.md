The zero-dependency [`proofpress.py`](../proofpress.py) CLI is the reference
implementation. Portable artifact and provenance documents are normative only
where they say so. The verified knowledge ledger is an implemented developer
wedge, not yet a frozen interchange specification.

[//]: # (ob:aef7f16a)
Proofpress provides a checkable record, not signed authorship, complete
capture, or a universal truth oracle. Product strategy and experimental
efficacy claims remain outside the public protocol contract.
