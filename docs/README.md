## Start here

[//]: # (ob:4ef44c57)
Proofpress governs whether an agent-produced conclusion may be reused, not the
documents or traces from which an agent worked. Start with the repository
[README](../README.md) for the product entry point, then choose the path that
matches what you need to do:

[//]: # (ob:d7e6b6d9)
- **Understand the model:** [product thesis](THESIS.md) and [verified knowledge
  and governed context](VERIFIED_KNOWLEDGE_LEDGER.md).
- **Connect an agent or workflow:** [trace integration](TRACE_ADAPTER.md),
  [MCP and WebMCP](WEBMCP.md), or [repository dogfood](REPOSITORY_DOGFOOD.md).
- **Run a private hosted workspace:** [single-owner self-hosting](SELF_HOSTING.md).
- **Understand prior experiments:** [study catalog](../studies/README.md).
